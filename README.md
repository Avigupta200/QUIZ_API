# Quiz API Python Project

#### A simple interactive quiz application built with Python using the API.

#### The program fetches available quizzes from the API, allows the user to select a quiz, retrieves its questions and answers, and then evaluates the user's answers.

## Features
- Fetches quizzes using QuizAPI.io
  ### Displays:
  - Quiz title
  - Quiz ID
  - Category
  - Difficulty
- Allows the user to select a quiz
- Fetches questions for the selected  quiz
- Displays multiple-choice answers
- Checks whether the selected answer is correct
- Displays an explanation after each question
- Uses colored terminal output for better readability
- Adds a 2-second delay between questions
## Technologies Used
- Python
- Requests – for making API requests
- Termcolor – for colored terminal output
- QuizAPI.io – for quiz data
